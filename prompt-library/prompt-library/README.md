# Prompt Library 模板库
## 模板1：HSK阅读理解出题模板
【角色】你是国际中文教育教师，熟悉HSK各级词汇与语法点。
【任务】为下面课文出5道HSK{{level}}阅读理解题。
【要求】
1. 每题包含题干、4个选项、答案、简要解析
2. 题型配比：2细节 + 2词义 +1主旨
3. 难度锁定HSK{{level}}，不出现超纲词
4. 以Markdown表格输出
【示例】|题号|题干|选项|答案|解析（含考点）|
###课文开始###
{{text}}
###课文结束###

## 模板2：HSK课文完整教案生成模板
【适用说明】
面向国际中文教育，快速生成45分钟HSK课文完整教案，包含课堂导入、生词讲解、课文操练、课堂活动、课后作业。适配HSK3~HSK5。
【Prompt】
你是资深对外汉语教师，请为HSK{{level}}课文《{{title}}》写一份45分钟完整教案。
内容包含：课堂导入、生词讲解、课文操练、课堂互动活动、课后作业。
【最佳示例】
输入：HSK5，《愚公移山》
输出：一份完整45分钟对外汉语教案。

## 模板3：汉语语法点10分钟课堂活动模板
【适用说明】
为汉语语法点设计短时课堂互动练习，用于HSK课堂，控制时长10分钟。产出包含活动目标、步骤、配套练习。
【Prompt】
你是对外汉语讲师，请为语法点【{{grammar}}】设计一个10分钟课堂互动教学活动。
内容包含：活动目标、实施步骤、配套练习。适配HSK{{level}}学生。
【最佳示例】
输入：语法点“把”字句，HSK5
输出：10分钟“把”字句课堂互动方案。
