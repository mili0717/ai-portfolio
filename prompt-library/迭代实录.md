# 迭代实录：HSK阅读理解出题模板
迭代目标：解决出题难度不稳、格式混乱、缺乏解析三大顽疾

## R1｜零约束 · 普通提示
Prompt：根据课文出5道题
Bug：输出大多是简答题，不是单选题；词汇难度不可控，出现超纲词；无固定格式、没有答案解析。
改进方向：增加角色定义，明确题型，强制规定输出结构。

## R2｜加格式 + 角色 + 表格
Prompt：你是国际中文教育教师，请为课文出5道HSK阅读单选题。每题包含题干、A/B/C/D四个选项、答案、简要解析。用markdown表格输出。
Bug：格式变成表格，但全部是细节查找题，缺少主旨题；解析过于简略，只写“见原文”，缺少考点说明。
改进方向：增加题型配比要求，强制解析标注考点。

## R3｜定标准 + 配比 + Few-shot示例
Prompt：
【角色】你是国际中文教育教师，熟悉HSK各级词汇与语法点。
【任务】为下列课文出5道HSK4阅读理解题。
【要求】
1. 每题含题干、4个选项、答案、简要解析
2. 题型配比：2细节 + 2词义 +1主旨
3. 难度锁定HSK4，不出现超纲词
4. 以Markdown表格输出
【示例】|题号|题干|选项|答案|解析（含考点）|
效果：题型配比稳定，难度符合HSK标准，解析附带考点。
遗留问题：用户粘贴的课文文本容易污染指令。
改进方向(R4)：增加分隔符###，隔离指令和课文内容。

## R4｜新增分隔符（学习OpenAI提示工程）
Prompt：
【角色】你是国际中文教育教师，熟悉HSK各级词汇与语法点。
【任务】为下面课文出5道HSK{{level}}阅读理解题。
【要求】
1. 每题含题干、4个选项、答案、简要解析
2. 题型配比：2细节 + 2词义 +1主旨
3. 难度锁定HSK{{level}}，不出现超纲词
4. 以Markdown表格输出
【示例】|题号|题干|选项|答案|解析（含考点）|
###课文开始###
{{text}}
###课文结束###
改动说明：学习OpenAI提示工程指南，使用###分隔符隔离指令与课文，防止输入文本干扰指令。
实测效果：AI不会混淆指令和课文，输出稳定性明显提升。
