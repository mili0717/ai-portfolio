## 参数体验表
|组别|temperature|max_tokens|效果描述|
| ---- | ---- | ---- | ---- |
|1|0.7|512|回答篇幅适中，讲解比较丰富，会举例，答案有一定创造性，每次回答措辞略有区别|
|2|0.2|100|回答简短精炼，知识点表述严谨稳定，几乎没有拓展，创造性低，多次提问答案基本不变|

### API调用四要素
1. base_url：接口地址，指定我们要访问的大模型服务地址
2. api_key：密钥，身份凭证，用来验证使用者权限
3. model：模型名称，选择调用哪一个大模型
4. messages：消息列表，存放系统提示词和用户提问内容
